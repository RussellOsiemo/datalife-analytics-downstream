# Security and Data Privacy Policy

## Supported versions

This repository is in the scaffold phase. Only the latest commit on `main` is in
scope; there is no production release or security-update promise yet.

## Reporting

Do not open a public issue for a vulnerability, privacy leak, re-identification risk,
credential exposure, or accidentally published dataset. Email
`auroral.sunflower@gmail.com` with the affected commit or artifact, impact,
reproduction, and containment steps. You should receive an acknowledgement within
five business days. Please coordinate disclosure while the issue is contained. This
project does not currently operate a bug-bounty program.

Do not download or further distribute exposed data. Never attach real patient data,
live credentials, or unauthorized records to a report. If a secret was committed,
rotate it immediately; removing it from the latest Git tree is not sufficient.
